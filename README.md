# 首领助手

> **⚠️ 仅供学习研究使用，请勿用于商业用途或破坏游戏正常秩序。**

勇者联盟的原生 macOS 辅助工具：检测首领、持续攻略、处理已适配弹窗、记录红包与事件，并提供游戏前台键盘控制。

[下载正式版](https://github.com/HuLuca1998/boss/releases/latest) · [所有版本](https://github.com/HuLuca1998/boss/releases) · [发布与测试流程](docs/发布与更新.md)

自动攻略期间每 2 小时正常退出并重新打开游戏，主界面显示逐秒重启倒计时。重启后保留区域与首领选择，等待连接、角色及场景就绪后继续；停止攻略取消计时，账号保护、手动移动、附近集火或维护期间延后重启。助手更新保留原倒计时，重启失败 60 秒后重试。

## 支持环境

| 项目 | 支持范围 |
| --- | --- |
| 系统 | macOS 14 及以上 |
| 芯片 | Apple Silicon，arm64（M 系列）；未提供 Intel 版本 |
| 游戏 | 本机运行的勇者联盟 1.16.3；支持 Main-40920、Main-f648a 与 Main-dda2f 热更新，未知脚本拒绝注入 |
| 运行方式 | 原生 SwiftUI 助手 + 本机回环连接，仅修改已适配游戏缓存，不修改游戏 App 签名 |
| 网络 | 游戏服务器；软件更新需要访问 GitHub 及其下载服务 |
| 权限 | 游戏缓存目录访问；键盘功能需要 macOS 输入监控 |

当前发布包使用固定本地代码签名，未使用 Apple Developer ID 签名或公证。已在开发者本机验证；其他 Mac 的首次安装与授权尚未验证。固定签名可以保留同一台 Mac 上后续更新的应用身份，但新机器、系统重置权限或更换证书后仍需重新授权。

不支持 Windows、Linux、Intel Mac，不保证后台或最小化状态下游戏持续运行。游戏本身可能停帧、暂停导航或掉线；助手保留任务不等于游戏后台仍在执行。

## 功能

| 功能 | 当前行为 |
| --- | --- |
| 首领检测 | 当前区域普通首领、区域 BOSS、刷新状态、倒计时与解锁信息；过期数据不冒充实时状态 |
| 首领勾选与装备筛选 | 逐个勾选，按区域记忆；按所需装备部位多选筛选，显示游戏配置的等级与部位预览；仅攻略勾选且匹配的目标 |
| 自动攻略 | 循环选择目标，游戏原生寻路和自动战斗；冲突、场景未就绪等情况保留任务等待 |
| 副本与位置 | 区分野外、其他区域、副本和加载；回到原攻略区域后恢复，可点“立即继续”跳过等待 |
| 区域 BOSS | 有真实钥匙且确认刷新时攻略；只为本次目标开启掉落宝箱，不购买钥匙或使用替代道具 |
| 附近怪物 / 集火 | 浮窗显示游戏可选范围内的存活敌方怪物，单体及总血量百分比进度每半秒更新（总量按当前列表剩余血量之和 / 最大血量之和计算，包含图腾）；按当前剩余血量排序，同名怪物独立显示；可手动点选，也可单独开启自动集火最高血量（默认关闭，跳过名字包含“图腾”的怪物），手动选择会退出自动模式 |
| 方向键 / WASD | 仅游戏前台读取；松键、切换窗口和输入文字时停止转发，不影响其他软件打字 |
| ESC 返回 | 每按一次返回一层，支持背包、商店、活动等公共返回组件及普通关闭弹窗；不代替购买、领取或确认 |
| 断线与异地登录 | 已适配的断线确认自动重试；60 秒内第二次异地登录暂停自动攻击和重连，1 小时后重试，也可手动解除 |
| 弹窗处理 | 分别勾选断线、异地登录、挂机收益、空白关闭（含恭喜获得）等规则，未知弹窗仅记录 |
| 红包 | 世界 / 联盟新红包立即尝试领取；资格、去重和安全锁检查保留，结果与金额以服务器确认为准 |
| 事件记录 | 软件内查看全部事件、红包、弹窗历史、JSON 与 ESC 返回结果，数据保存在本机 |
| MCP 服务 | 正式 App 内附本机 stdio 服务，9个探索工具，支持按需连续状态观察与图片返回；需要 Node 22+，[接入说明](docs/MCP服务.md) |
| 本机探索 API | 令牌鉴权的回环 WebSocket；区域与子地图、采集与宝箱进度、已观测迷雾、界面树与渲染图、只读战斗和寻路状态、原生单事件寻路、位置移动与按钮点击；[接口说明](docs/探索API.md) |
| 软件更新 | 设置 → 关于与更新，检查正式版本、查看说明、一键下载、验签、安装并重开助手，失败回滚 |

键盘功能共用一个开关。未知自定义回调不强制执行，未知弹窗不泛点。秘境试炼、突袭、突袭困难的自动导航不属于当前已完成能力。

## 安装与使用

1. 从 Releases 下载 `BossAssistant-x.y.z-macos-arm64.zip`，解压并将“首领助手.app”放到 `/Applications`。
2. 首次打开助手，点击“注入脚本”，按需选择游戏 appCache 目录。先备份原始缓存，再正常重启游戏一次；按当前热更新目录识别真实主脚本，未适配版本拒绝注入。
3. 进入角色后，确认实际区域和最新首领列表，选择所需装备部位并勾选目标，点击“开始自动攻略”。“停止攻击”是主动结束任务的入口。
4. 设置 → 辅助功能，选择键盘、红包与区域 BOSS 选项；键盘权限未生效会明确提示。
5. 侧栏 → 附近怪物 / 集火，开启列表后手动选择；自动集火可独立开关。面板切回游戏仍显示，关闭窗口会停用本功能；开启期间保留并暂停首领巡检，关闭后允许恢复。
6. 设置 → 弹窗处理，选择处理类型；事件记录中查看红包和弹窗详细数据。

游戏缓存：`~/Library/Containers/com.yzlm.game/Data/Library/Caches/appCache`。

用户数据：`~/Library/Application Support/HeroBossAssistant/`，保存事件、弹窗、红包、钥匙、备份和连接信息。软件更新不清空这些数据。

## 一键更新

设置 → 关于与更新 → 检查更新 → 一键更新。显示真实下载进度，可取消；失败可重新下载。成功后只重开助手，保留设置、事件与攻略意图，不自动重启游戏。

新版若有游戏脚本变化，另外点击主界面“重新注入脚本”，该操作会重启游戏一次；更新器不自动改游戏缓存。应用目录不可写时提示，不自行申请管理员权限。

只接收本仓库正式版的匹配 arm64 包与校验文件，验证 SHA256、版本、应用标识和固定证书，拒绝篡改、异常目录和错误身份，替换失败恢复旧 App。

## 开发与发布

源码在 `BossAssistant/Sources`，游戏脚本在 `BossAssistant/Resources/Runtime.js`，安装器在 `BossAssistant/Updater`。

```sh
# 本机构建
npm ci --prefix mcp
zsh BossAssistant/build.sh

# 自动化检查
node BossAssistant/Tests/keyboard-runtime.cjs
node BossAssistant/Tests/assistance-runtime.cjs
node BossAssistant/Tests/location-runtime.cjs
node BossAssistant/Tests/targeting-runtime.cjs
node BossAssistant/Tests/exploration-runtime.cjs
swiftc BossAssistant/Sources/GameCachePolicy.swift BossAssistant/Tests/GameCachePolicyTests.swift -o /tmp/game-cache-tests
/tmp/game-cache-tests BossAssistant/Resources
zsh scripts/test-update.sh
zsh scripts/test-update.sh --installer
```

构建需要 Apple Silicon Mac、Swift 编译工具、脚本指定的 macOS 26.5 SDK，以及登录钥匙串的固定签名证书。构建 SDK 不等于用户运行系统下限，运行下限为 macOS 14。

安装器测试仅操作临时应用副本。GitHub CI 不持有私钥；正式包在签名 Mac 上构建发布。私钥不提交、不上传，证书缺失则拒绝构建。

完整版本、发布、恢复和本机一键更新步骤见 [发布与更新](docs/发布与更新.md)。规范参考 [HuLuca1998/acpp](https://github.com/HuLuca1998/acpp) 的标签、Release 和“关于与更新”流程，本软件使用原生 Swift 更新器。

热更新适配按当前 DCC 目录中的主脚本名称、对象编号与原始内容 SHA256 共同校验。注入和还原只处理当前主脚本及对应编译缓存，原始备份按内容哈希分目录保存。未知热更新会停止操作并提示；断连时键盘、红包与弹窗显示等待连接。

账号保护触发后暂停 1 小时，界面显示登录重试倒计时，到时恢复原有登录确认流程；再次触发保护重新等待 1 小时，也可手动解除。保护截止时间随助手重启保存；旧版保护状态首次升级后开始计时。关闭异地登录自动确认时仍尊重该设置。

主界面提供“打开游戏”和“重启游戏”按钮。手动重启保留攻略任务并重新开始 2 小时计时，操作失败显示原因。

主页首领改为每排 4 张卡片，用状态指示灯、当前目标边框及钥匙/区域BOSS图标减少重复文字，保留勾选、地图、掉落、装备等级及冷却。移除顶部三个统计总览，顶部显示重启倒计时，图例、悬停和无障碍说明解释状态。

1.5.0 使用两行紧凑卡片，每排4张，每页最多20张；保留地图编号、冷却、等级/掉落及状态灯，超过20个通过分页查看。

设置 → 辅助功能可调整自动攻略重启间隔（1分钟测试、5/15/30分钟、1/2/4/6小时），默认2小时；修改后重新计时。
