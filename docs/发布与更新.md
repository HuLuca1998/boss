# 发布与更新规范

## 版本与资产

- 仓库 HuLuca1998/boss，软件显示名称“首领助手”，分支 main。
- 标签 vx.y.z；VERSION、CFBundleShortVersionString、标签和包名必须一致，BUILD_NUMBER 每版递增。
- 默认顺序参考 ACPP 逢十进位：1.3.8 → 1.3.9 → 1.4.0，1.9.9 → 2.0.0。跳号明确说明，不覆盖已发布版本。
- 说明保存在 docs/releases/x.y.z.md，写清功能、修复、环境和未验证限制。
- 资产为 BossAssistant-x.y.z-macos-arm64.zip 和同名 .zip.sha256，ZIP 顶层为“首领助手.app”。
- 草稿、预发布、缺少匹配安装包或校验文件的版本不进入更新列表，版本按数字排序。

## 签名

仅在持有 BossAssistant Local Signing 私钥的 Mac 上正式构建；主应用指定要求固定为应用标识和证书指纹，安装器也签名并封入 App。私钥不提交、不上传 Release 或 CI。证书缺失时构建失败，不能临时新建同名证书或改用 ad hoc。

本机已验证更新后输入监控授权保留；新机器、证书更换或系统重置后仍需授权。当前未提供 Developer ID 公证，不宣称其他 Mac 可免提示安装。

## 发布前检查

1. 更新 VERSION、BUILD_NUMBER、版本说明和 README 支持范围。
2. 执行三个 Runtime 测试、zsh scripts/test-update.sh，完成本机构建。
3. 执行 zsh scripts/test-update.sh --installer，验证签名、版本、错误包拒绝、替换成功和安装失败回滚，仅操作临时副本。
4. 审阅 git diff，不能包含私钥、Connection.json、账号数据、用户事件或构建产物，提交源码与文档。
5. 工作区保持干净，确认 origin 和版本。脚本拒绝未提交改动、重复标签和错误仓库。

## 发布命令

```sh
# 仅构建、验签、打包、校验和，不推送或发布
zsh scripts/release-macos.sh 1.3.8 --prepare-only

# 正式发布，省略版本时读取已提交 VERSION
zsh scripts/release-macos.sh 1.3.8
```

从已提交版本构建到 BossAssistant/build/release/x.y.z，不覆盖真实安装或日常构建。验证后生成 ZIP+SHA256，建立注释标签，推送 main 与标签，上传 GitHub Release 草稿，最后公开为正式版。产物保留在被忽略目录，方便排错。

只准备过产物后再完整发布，先检查并移走对应输出目录，避免误用旧包。已公开版本的资产不可覆盖。

## 中断恢复

- 构建或验签失败：修复本机环境后重新构建，不发布未验签包。
- 本地标签已建但推送失败：核实标签指向，再单独推送原标签，不重打同名标签。
- 标签已推送但没有 Release：使用原标签与已核验资产创建草稿，核验 SHA256 后公开。
- 草稿上传不完整：只修复尚未公开的草稿，公开前必须同时存在 ZIP 和 SHA256。
- 已公开后发现问题：撤下“最新”标记并发布更高版本修复，不替换同版本文件。

## 软件内更新

设置 → 关于与更新，检查最近 30 个 Release，过滤草稿和预发布，展示最新版本及最多五个待更新版本说明。本仓库匿名 HTTPS 下载，不内置 GitHub Token。

一键更新顺序：真实下载进度 → SHA256 → ZIP 目录检查 → 解包 → 固定签名/版本/标识验证 → 保留任务并正常退出助手 → 独立安装器等待退出 → 同目录准备新 App → 替换并复验 → 重开助手。安装失败回滚；网络或校验失败不动当前版本。取消后可重新下载，当前不提供断点续传。

不修改游戏进程、用户数据或权限数据库；游戏脚本变化需用户另行点击重新注入。应用目录不可写、脚本正在处理或助手未正常退出时不替换并显示原因。

## 本地端到端验证

1. 备份已安装 App，采用同一证书构建带更新入口的旧版本基线。它是测试用基线，不声称旧版原本自带更新器。
2. 正式版发布后，在基线中检查版本、说明、准确资产，点击一键更新。
3. 观察下载、校验、退出、原路径替换和自动重开。
4. 核对安装版本、签名、游戏连接、攻略意图、输入监控和已有事件，游戏不应被更新器重启。
5. 再查更新应为最新版本，把实际范围和结果记入 Validation.json。
6. 本机成功不等于跨设备验证。新 Mac、本地证书信任和网络环境限制继续保留在 README。

模拟测试验证错误包、篡改、ZIP 路径/符号链接和回滚；真实 UI 验证完整升级。分别记录两类证据，不用模拟替代实机结论。
