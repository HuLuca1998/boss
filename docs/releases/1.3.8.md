# 首领助手 1.3.8

- 新增「设置 → 关于与更新」：检查版本、查看更新说明、一键下载安装并重开助手。
- 更新前校验安装包 SHA256、应用身份与固定签名；安装失败恢复旧版本。
- 保留设置、事件记录、键盘授权和攻略任务；更新助手不会自动重启游戏。
- 统一 ESC 返回背包、商店及使用公共返回组件的页面；输入文字时不处理。
- 支持 macOS 14 及以上的 Apple Silicon Mac，当前仅适配勇者联盟 1.16.3。

本版本使用本机固定代码签名，未使用 Apple Developer ID 签名或公证；其他 Mac 的首次安装与权限流程尚未验证。新机器仍需由使用者授予输入监控等必要权限。后台游戏停帧问题不属于本次更新修复范围。
