# 首领助手 1.5.3

新增宠物技能快捷键：1 / J、2 / K、3 / L 依次对应技能栏前三个宠物技能。Q 切换当前游戏界面的自动战斗按钮。共用键盘控制开关，仅游戏前台生效，每次按下触发一次，按住及连接心跳不会重复触发。

沿用游戏原生按钮与技能条件；未解锁、冷却、能量不足、自动施放导致按钮禁用时不会强制施放。聊天输入、弹窗、切场景和跟随队长时不触发，保留原有方向键、WASD 与 ESC 行为。设置页增加按键说明，事件记录显示原生操作请求或未执行原因。

验证：新增原生键位/别名去重/释放测试，以及 Runtime 三技能槽、Q 单次切换、原生拒绝、聊天/弹窗/场景/禁用保护回归。正式构建与安装器验证由固定签名 GitHub Actions 执行。

环境：Apple Silicon，macOS 14+，勇者联盟 1.16.3。更新后需重新注入脚本并重启游戏一次。未逐一实测所有副本和宠物技能；定向技能按原生单击行为处理，不提供键盘拖动瞄准。
