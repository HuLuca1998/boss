# 首领助手 1.4.2

支持勇者联盟 1.16.3 的 Main-dda2f 热更新。此前助手会将其识别为未知版本并拒绝注入；现在可识别当前 DCC 主脚本，核验原始内容，按版本备份、注入和还原。保留 Main-40920 与 Main-f648a 支持，未知脚本继续拒绝修改。

包含此前本机修改：账号保护期间主界面提供“解除保护，恢复辅助”入口，并明确提示自动重连、红包领取与攻击已暂停；解除保护不启动自动攻略。

验证：四组 Runtime 回归、三个版本的缓存身份与原始哈希检查、更新器签名/错误包拒绝/失败回滚测试通过。Apple Silicon 本机已注入新版脚本并连接，读取红叶王庭 17 个首领、位置和钥匙，实测三个普通首领进入冷却，停止时确认取消跟随并关闭自动战斗。

支持 macOS 14+、Apple Silicon。固定本地签名，未做 Developer ID 公证；其他设备、实际区域 BOSS 钥匙消耗、自然红包结果及全部弹窗分支未在此次重新验证。
