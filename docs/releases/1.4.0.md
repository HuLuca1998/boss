# 首领助手 1.4.0

> **⚠️ 仅供学习研究使用，请勿用于商业用途或破坏游戏正常秩序。**

- 适配 2026-10-26 的 Main-f648a 游戏热更新，保留 Main-40920 支持。
- 从当前游戏更新目录定位主脚本，校验名称、对象编号与原始内容；未知热更新明确提示，避免注入失效的旧文件。
- 原始缓存按版本分别备份；还原对应当前版本，清理对应编译缓存。
- 游戏退出期间缓存发生变化时停止改写；写入校验失败或重开失败时尝试回滚脚本与编译缓存。
- 断连时键盘、红包和弹窗显示等待连接，清除过期可用状态。
- 脚本返回实际适配身份，便于确认当前加载版本。

验证：本机安装并注入后重新连接，红叶王庭 17 个首领、刷新状态和区域钥匙读取恢复；普通首领连续三个进入冷却，停止攻击成功；当前版本还原后原始 SHA256 核验通过；键盘授权保留，记录到 ESC 原始返回事件。热更新目录与内容校验、未知版本和异常路径拒绝、键盘/辅助/位置回归与更新器隔离测试通过。自然红包领取、区域钥匙实际消耗和所有弹窗分支未逐项重新实测。

环境：Apple Silicon Mac，macOS 14+，勇者联盟 1.16.3。更新助手后需重新注入脚本，游戏重启一次。仅更新助手不会自动注入或重启游戏；未知后续热更新仍需单独适配。使用固定本地签名，尚无 Apple Developer ID 公证，其他 Mac 的首次安装与授权未验证。
