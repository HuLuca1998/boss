# 首领助手 1.4.3

自动集火最高血量时，跳过名字包含“图腾”的怪物。普通怪物按当前剩余血量排序；只剩图腾时等待普通怪物出现。已由助手选择的目标变为图腾时，释放该目标。图腾仍显示在附近列表，可手动点选；手动点选仍退出自动模式。

验证：针对高血量图腾、名字开头/中间/结尾包含图腾、同血量图腾、只有图腾、普通怪物重新出现、目标名字变化、手动选择的运行脚本回归测试通过。其余 Runtime、缓存和发布检查随正式发布执行。

支持 macOS 14+、Apple Silicon，勇者联盟 1.16.3 已适配热更新。固定本地签名，未做 Developer ID 公证；实机图腾场景仍需以实际出现为准。
