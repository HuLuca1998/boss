# 首领助手 1.4.5

新增供本机工具使用的探索 API：读取区域、子地图、事件分类计数、采集与宝箱状态、已观测迷雾、界面节点树和引擎渲染图；可执行原生单事件寻路、位置移动、按钮点击和停止。控制器使用本机令牌鉴权，不替换游戏连接，不开放任意脚本执行。首领攻略、附近集火、账号保护或维护中拒绝冲突操作。

单事件接口排除方尖碑、聚魂匣与神像。点击编号随界面快照过期，操作是否完成必须重新观察。详见 docs/探索API.md；本版提供逐步操作接口，不宣称已经实现无人值守全图探索。

支持 macOS 14+、Apple Silicon、游戏 1.16.3 的三个已适配热更新。固定本地签名，未做 Developer ID 公证。地图和界面用模拟数据做回归；真实新地图未在开放前验证。截图依赖引擎 Conch 渲染方法，可能仅有 UI。更新后需重新注入并验证游戏连接。
