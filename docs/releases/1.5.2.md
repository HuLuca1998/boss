# 首领助手 1.5.2

- 设置 → 辅助功能新增“换向释放延迟”：0–300毫秒，步长10毫秒，默认80毫秒；0关闭延迟。自动保存并立即生效。
- 修复左右、上下换向时反向键重叠被客户端抵消成停止移动的问题；优先采用后按下的方向，松开后恢复仍按住的旧方向。
- 短暂全松时保持方向至配置的延迟结束，新方向到达立即接管；失焦、关闭控制、聊天输入与连接过期不沿用延迟。ESC 不延迟。
- 游戏原始按键不再覆盖助手已处理的方向，避免再次抵消。

延迟越大，彻底松键后继续移动越久；实际检测受40毫秒采样周期影响。同一采样内同时按下的反向键无法判断真实先后，优先保持已有方向，无已有方向时采用固定顺序。

支持 macOS 14+ / Apple Silicon、勇者联盟1.16.3与现有三个已适配热更新脚本。运行脚本有变化，更新后需重新注入。本次输入逻辑通过模拟时序与 Runtime 测试；真实游戏换向手感及跨设备效果尚待验证。本版迁移到新的固定签名，由 GitHub Actions 使用加密签名包构建；旧电脑上的签名私钥已不可用。旧版一键更新无法验证新签名，必须手动安装本版正式包，输入监控可能需要重新授权；后续版本恢复一键更新。
