# 首领助手 1.4.1

> **⚠️ 仅供学习研究使用，请勿用于商业用途或破坏游戏正常秩序。**

- 修复自动攻略已关闭时，账号保护后台轮询仍重复修改自动技能，导致跟随队长时持续弹出限制提示的问题。
- 跟随队长时拒绝助手的攻略启动与自动技能修改；账号保护只清理助手自己的攻略操作。
- 新增首领逐个勾选、当前结果全选/取消全选，按区域保存。
- 新增装备部位多选筛选、掉落部位与等级预览；仅攻略勾选且匹配的目标，取消当前目标后停止它并保留任务。
- 新增「附近怪物 / 集火」浮动面板，显示游戏可选择范围内的存活敌方怪物。
- 紧凑百分比进度条，每半秒刷新；同名、重叠怪物按独立实体区分，点击即可调用游戏原有集火操作。
- 按当前剩余血量从高到低排列；自动集火最高血量为独立开关，默认关闭，手动点选会退出自动模式。
- 列表随目标数量调整高度，数量多时分栏；切回游戏仍保持可见。
- 关闭列表或窗口会关闭自动模式，只取消本功能拥有的选中目标；断连后自动模式关闭。
- 保留游戏距离限制，拒绝死亡、离开范围、切换场景或账号保护期间的过期选择；开启列表时暂停首领巡检以避免互相抢目标。

升级助手即可阻止旧脚本在账号保护期间重复操作；附近怪物等游戏脚本功能需在合适时机点击「重新注入脚本」（会重启游戏）。

已通过四组运行时回归、首领筛选测试和本机构建验证；跟随提示问题已复现并通过回归测试，修复后的原场景实机复测尚未完成。掉落预览为可能产出，不保证掉落。

本机验证与具体限制见 Validation.json。环境与热更新支持范围沿用 1.4.0。
