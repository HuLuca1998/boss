# 首领助手 1.4.7

新增随正式 App 打包的本机 MCP 服务（Node 22+），提供地图、状态、界面、JPEG图像、移动、单事件跟随、点击、停止和最长30秒的连续状态观察。采用本机 stdio 协议，操作请求/响应，观察可发送标准进度通知并返回变化快照；不开放额外网络端口，不在配置中保存令牌。

探索 API 新增只读 exploreState：返回实际场景、角色血量/死亡与自动战斗状态、选取范围内敌人的独立实体 ID、血量、位置和选中状态，以及单事件寻路、目标坐标和跟随状态。读取不会开启附近集火或选择目标，可用于对比移动前后和确认是否进入战斗；加载或未就绪时返回未知状态。

地图事件补充本地化说明和原生前置条件，迷雾补充每个数据字的位数，明确未知跟随 ID 为 null。仍须以实际界面和状态变化验证操作完成；新地图的采集、宝箱和首领击杀在开放前尚未验证。

macOS 14+、Apple Silicon、游戏 1.16.3 已适配热更新。固定本地签名、未公证，仅验证本机。更新后需要重新注入。
