# 勇者联盟 · 首领助手

原生 Apple Silicon Mac 应用，支持游戏 1.16.3。游戏操作通过本机脚本桥执行，不模拟鼠标键盘。

## 使用

1. 打开“首领助手”，点击左下角“注入脚本”。首次使用时，按提示选择游戏的 `appCache` 缓存文件夹。应用会先保存原始脚本，再注入并重启游戏。
2. 游戏进入角色界面后，助手会自动检测；也可点击“重新检测”。应用重新读取角色当前区域、地图、普通首领和冷却信息；换区后再次点击即可，不需要重新注入。
3. 点击“开始自动攻略”。助手只处理当前区域已确认刷新的普通首领，跳过冷却、未解锁和未知状态。它会自动开启游戏自动战斗，并持续等待下一次刷新。
4. 点击“停止攻击”，会立即停止派发目标、取消跟随并关闭自动战斗。退出助手会暂停派发，重新打开并连接游戏后恢复保存的任务。连接断开时，游戏内控制桥取消旧跟随；助手保留攻略意图，等待连接及原区域恢复后重新检测继续。

左侧展示19个区域及当前角色的解锁情况。选择其他区域只查看配置，不会直接传送。重新检测会回到角色实际所在区域。

## 注入与还原

只改动游戏数据目录中的已适配脚本缓存；不修改 `/Applications/game.app` 的签名或系统安全设置。注入、重新注入和还原都需要重启游戏一次。

“还原原始脚本”恢复校验过的原始缓存，并让游戏重新生成编译缓存。原始备份与日志位于：

`~/Library/Application Support/HeroBossAssistant/`

首次授权仅选择：

`~/Library/Containers/com.yzlm.game/Data/Library/Caches/appCache`

应用和游戏更新后若需要再次选择该目录，请按提示重新授权。新游戏版本会拒绝注入，需重新适配。

## 状态与边界

“已刷新”由客户端收到的地图复活数据和服务器时间计算，未加载的数据不会当作已刷新。该状态可能因其他玩家击杀而立即改变。

每次前往后核验同一实例和刷新点是否出现冷却；75秒有效战斗时间未出现冷却时，仅暂缓当前目标，继续处理其他首领；60秒后可重试同一目标，不停止整轮、不弹超时窗口。角色进入副本或离开本轮区域时暂停派发，返回原攻略区域并完成加载后自动刷新首领状态、重新选目标继续。副本停留时间不计入75秒等待。暂停时仅取消野外跟随，不改变副本自动战斗；副本内移动按键不会取消等待返回的攻略任务。只有点击“停止攻击”或选择停止菜单才取消本轮；短暂断线、场景加载、副本和按键接管都保留任务并等待恢复。

启动攻略时助手保持活动，避免助手自身被系统节流或自动终止。这不能保证游戏在窗口完全不可见时仍推进画面与战斗。后台补帧实验已撤回，不包含在当前应用资源中。系统休眠及锁屏后的长期运行未验证。没有创建定时任务。


## 方向键控制

助手默认开启“方向键 / WASD”，切回游戏窗口后，按住 ↑ ↓ ← → 或 W A S D 控制角色，松开停止；两组按键可以混用，支持斜向。同方向的两个按键同时按住时，松开其中一个仍继续移动。仅在游戏前台轮询按键，不模拟鼠标、不安装全局键盘监听。聊天输入时暂停映射；切到其他应用清除按键状态，转发中断超过900毫秒自动松键。

开关设置自动保存。游戏重启或连接恢复后，助手会等待角色就绪、自动检测当前区域并恢复已开启的键盘控制；角色加载较慢时继续每3秒检查，无需重新注入或手动反复检测。手动关闭后不会自动开启。开启按键开关只恢复按键映射，不结束攻略任务。启动自动攻略不再关闭按键开关；游戏前台的有效移动按键会临时暂停自动派发，松键60秒后自动尝试继续攻略。游戏内聊天输入不会触发接管。不可移动的界面仍服从游戏限制。

WASD 字母键需要 macOS 的“输入监控”权限。若助手显示“授权 WASD”，点击后在系统设置 → 隐私与安全性 → 输入监控中启用“首领助手”，按系统提示重启助手。读取按键前先检查游戏是否在前台；其他应用有焦点时不读取、不转发任何移动键。权限由系统管理，助手不会自动授予。

## 当前位置与副本续打

1.0.2 起，标题下方显示当前实际场景名称与可用坐标；副本内显示副本名称。旧脚本只保存最近的野外区域，无法判断当前位置，必须重新注入一次才能启用此功能。

自动攻略以启动时所在区域为续打区域。在红叶王庭启动后，即使被组队拉入副本，助手会显示“副本中 · 已暂停，等待返回红叶王庭”，持续检测；回到红叶王庭后自动继续，不会强行退出副本或传送回去。在其他野外区域停留也会等待原区域。场景切换和传送期间不派发新目标，旧传送回调也会再次核对场景，避免进入副本后恢复野外跟随。

## 持续重试与恢复版（1.0.3）

首领超时不再弹窗并终止整轮，而是暂缓失败目标并继续巡检。游戏时间停住、传送、场景加载和副本停留期间均不消耗首领等待预算。短暂响应失败及断线不会取消任务，恢复后重新检测并选目标。关闭助手窗口时若攻略仍在运行则保持进程；退出后保存任务，重新打开时恢复；点击停止才取消。

恢复版撤回了后台帧更新实验。游戏必须已进入角色、当前战斗场景就绪，助手才读取完整首领列表和恢复按键控制，避免在启动加载过程中调用未就绪的游戏功能。连接数据统一在主线程处理；通过2000个并发请求与100个断线待处理请求的测试。键盘开关显示保存的用户设置；游戏暂时断线只暂停实际转发，不再把开关自动改为关闭。

全屏视频遮挡游戏时继续自动寻路与攻击，目前尚未解决。仅让助手保持活动，不能保证游戏引擎在后台继续推进；请勿将其视为已验证的后台挂机功能。

## 持续任务与按键恢复（1.0.4）

任务是否开启与当前能否操作游戏分开保存。开启任务后每3秒检测连接和实际场景；副本、传送、断线、未就绪、暂时无进展等情况只暂停派发。恢复后等待剩余60秒重试间隔，重新读取首领列表继续。超时目标延后60秒，不影响其他可用目标。手动移动时暂停自动派发，松开方向键或WASD后60秒尝试续打。不会因开启键盘开关而取消任务。

仅手动停止会清除任务意图；关闭窗口继续运行，意外重开助手时恢复保存的任务，主动退出助手时保存任务，重新打开后恢复。键盘开关独立保存，连接中断不把开关改为关闭。按键转发串行合并最新状态，只轮询游戏有焦点时的八个移动键；WASD字母键需在macOS中授权输入监控。游戏内聊天输入暂停移动映射。

当前助手不调用试炼采集或包装战斗函数；新打包的游戏桥已移除这部分历史诊断入口。没有修改伤害、掉落、游戏时钟、引擎帧循环或窗口焦点。后台完全不可见时游戏自身可能暂停，助手会保留任务继续检测，不能保证游戏此时仍实际战斗。

## 立即继续与授权（1.0.5）

暂停任务时，在“停止攻击”旁显示“立即继续”。点击跳过60秒倒计时并唤醒检测，不重置已核验数量或攻略区域。仍在副本、加载或游戏没有推进时继续等待安全场景；方向键尚未松开时提示先松键。每3秒自动检测与60秒自动重试继续作为兜底。

应用重开（包括系统要求权限生效而重开）保留持续任务；停止按钮和停止菜单才清除任务。更新旧版本至此版时，旧版退出逻辑仍可能清除任务，需要重新点一次开始。

当前构建采用临时签名，更新可使旧输入监控授权记录失效，即使系统列表仍显示开启。此时从输入监控列表移除旧条目，添加 `/Applications/首领助手.app` 并退出重新打开。稳定继承更新授权需要使用同一受认可的代码签名身份；当前机器未配置可用的正式签名证书。

## 自动重连、异地登录保护与聊天红包（1.1.0）

界面提供独立的“断线自动重连”和“世界/联盟红包自动领取”开关，默认开启，修改后保存。每3秒进行一次与野外首领快照独立的辅助检查，角色尚未加载时也可以识别已显示的登录提示。没有引擎补帧、后台生命周期拦截或登录函数替换。

重连仅针对已显示的1137/1183登录提示、游戏登录失败步骤处于活动状态、确认动作是绑定的Retry且非H5退出分支；其他弹窗、购买、选服、维护、SDK鉴权等不会被统一确认。执行前核对弹窗展示参数和代次，每代最多一次，确认间隔至少10秒。

异地登录同时观察200104错误及明确提示，事件和对应弹窗使用同一标识避免双计数。滚动60秒内第2次出现即持久锁定，暂停自动重连与自动攻击，保留任务；普通网络错误不能绕过此锁定，助手重开也不自动解除。点击“立即继续”（有攻略任务）或“手动恢复重连”（无攻略任务）解除；不会自动清除相同旧提示的去重记录。第一条已识别异地登录提示允许正常确认，第二条保留等待手动操作。

红包仅筛选世界1000与联盟1004频道、类型8的红包消息，观察新消息事件并补扫已有缓存。不会主动发言、切换频道、标记聊天已读或拉取私聊。根据红包原始ID、频道、会话和类型查询/核验状态，跳过过期、已领取、领完和协作币上限；领取串行限频，只有服务端状态显示本角色已领才记录成功。未知领取结果只查询，不盲目重复发送同一领取请求。日志只写领取计数与登录处理结果，不保存普通聊天正文或领取者明细。

当前未主动拉取聊天历史，启动前未缓存或服务端未推送的消息不保证覆盖；游戏完全暂停、掉线时不能保证即时处理。红包领取资格与结果由服务器决定。不要把“监控中”或“请求已发送”等同于实际领到红包。

验证：新运行时模拟测试覆盖角色未就绪、同文案不同按钮操作、旧/重复确认、异地登录保护、事件/弹窗去重、频道过滤、长整数ID、服务器领取确认、未知结果不重发、协作币上限及上下文不匹配；Swift策略测试覆盖滚动60秒内两次、重复轮询去重、持久化锁定和手动解除。WASD、实际场景判断和原持续攻略测试通过。已安装并更新游戏缓存，现场正常加载进入红叶王庭、辅助功能状态正常；真实断线、异地登录与新红包的现场触发尚待自然事件验证，未人为断网或制造账号冲突。

## 软件内事件与红包账本（1.1.2）

点击左侧“事件记录”：全部事件页按连接、账号保护、红包、攻略、操作筛选，也可搜索标题、红包ID和详情数据。点击左侧一条事件，右侧查看其时间、结果和结构化字段。旧版Activity.log最近500条自动导入；新事件保存到Events.jsonl，软件显示最近最多3000条，重开后仍可查看。事件窗口不会暂停巡检。

“红包明细”页显示已发现红包、助手自动领取已核验数量，以及按不同游戏货币分别累计的本角色已领取金额（金额汇总明确包含此前/手动记录）。选择红包可看频道、类型、ID、发现时间、处理结果、本角色实际金额、总额与份数。已请求但未核验的记录不计金额；服务器小缓存淘汰不会清除已核验奖励，重复状态不会重复累计。

账本同时保存在本机红包记录.json与红包记录.txt；没有红包时显示真实的0与空状态。普通聊天正文、其他玩家聊天与领取明细不写入记录。“打开记录文件夹”保留作为导出入口。真实红包到来前不添加示例记录。

## 1.1.3 弹窗历史

软件内打开「事件记录 → 弹窗历史」，可搜索弹窗文字或组件 ID，并查看出现、变化、关闭事件和原始 JSON。记录包含可见文字、按钮、回调名称（不执行）、场景及经过限量和敏感字段过滤的参数。完整历史保存在本机 `~/Library/Application Support/HeroBossAssistant/弹窗历史.jsonl`，界面展示最近 2000 条，重开软件保留。

记录器只观察游戏 UI 事件和可见组件；不会为新弹窗自动点击。现有断线重连允许列表及异地登录保护规则不变。系统/SDK 原生弹窗、游戏暂停时或队列溢出时可能无法完整捕获。可见文案会原样保留，敏感参数按字段过滤。

## 1.2.0 设置与奖励弹窗处理

左下角「设置」分为「辅助功能」（方向键/WASD、世界/联盟红包）和「弹窗处理」（网络重连、异地登录确认、挂机收益领取、恭喜获得奖励展示关闭）。配置自动保存。收益与奖励默认仅在自动攻略期间处理；每个实例只尝试一次，弹窗保留至少2秒。自动处理动作和随后观察到的关闭事件写入弹窗历史，发出请求不代表已核验到账。

未知已收录组件展示为禁用项，提示待适配；消息浮层与场景切换提示交给游戏正常关闭，不自动确认未知通用对话框。

## 1.3.1 区域BOSS与刷新状态

首领列表增加区域BOSS、对应钥匙数量；切换区域可查看配置，只有当前区域且实时数据有效才用于自动攻略。有钥匙且服务器确认刷新时优先攻略区域BOSS；击败后仅处理本任务目标的原有宝箱界面，使用真实钥匙，不使用3361替代道具或购买。钥匙数量变化与开箱动作写入事件记录，服务器奖励返回另记确认事件。

刷新判定以服务器alive状态优先，无需复活时间字段。旧的未来时间不能压过alive；dead倒计时到零仍等待服务器确认。角色未就绪或数据超过10秒时不展示旧状态为实时状态。

空白关闭整合为一个开关，包含恭喜获得。仅处理游戏顶层mask2且有可见空白关闭提示、使用BaseView普通关闭逻辑的组件。自定义空白点击（例如开箱或跳转）不会误用统一规则，未开箱BOSS结算和挂机收益保留专用规则。

## 1.3.2 悬赏暂停时的寻路修复

游戏悬赏助手服务器状态仍为运行、客户端已经暂停时，普通追踪入口会拒绝开始移动。新版本对此使用游戏原有寻路和普通路径移动接口，不改悬赏任务设置；到达后启用游戏原有自动战斗。悬赏正在实际运行时显示冲突，不争抢控制。停止或手动接管只清理本助手创建的路径。区域BOSS有效战斗等待上限10分钟，普通首领仍75秒。

现场已核验青铜龙战斗伤害、冷却、自动钥匙开箱及服务器奖励返回；钥匙2→1。完整证据见attack-verification-2026-10-24.json。

## 1.3.3 钥匙耗尽保护

钥匙0时，除了跳过区域BOSS选择，还取消进行中的区域BOSS目标。若仍处于区域BOSS战斗区，先关闭该处自动技能，再按游戏允许的传送规则返回普通首领区域；暂时无法传送则保留任务继续检测。普通首领巡检继续，手动移动暂停期间不抢控制，不购买钥匙或消耗替代道具。退出动作记入事件记录。

## 1.3.4 内部背景的空白关闭

部分「恭喜获得」无外层mask标记，实际由CommonBg1SubView内部关闭按钮处理。统一空白关闭规则现同时支持这种内部背景：必须是原有关闭方法、按钮可见可用、拥有者正确且文案为本地化空白关闭提示。不会调用分享按钮；自定义处理方法和多候选歧义拒绝自动点击。开箱/领取与随后空白关闭分别去重。

## 本机固定签名与 ESC 返回（1.3.7）
